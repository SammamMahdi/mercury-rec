# MercuryRec

> Production-grade multi-stage recommendation and personalization platform combining
> candidate retrieval, neural embeddings, learning-to-rank, experimentation, serving,
> caching and monitoring.

This README is built out as the system lands. See `docs/` for design documentation.

## Status

Under active development. Every metric published here comes from an experiment
executed in this repository; nothing is estimated or illustrative.
